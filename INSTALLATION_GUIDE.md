# SURA-RESTO by SURA - Installation Guide

## 🚀 Quick Start

### Download Options
1. **Setup Installer** - `SURA-RESTO-by-SURA-Setup-1.0.0.exe`
2. **Portable Version** - `SURA-RESTO-by-SURA-1.0.0-portable.exe`

## 📦 Installation Methods

### Method 1: Setup Installer (Recommended)
1. **Download** the setup installer
2. **Run** the installer as Administrator
3. **Choose** installation directory (default: `C:\Program Files\SURA-RESTO by SURA`)
4. **Complete** installation
5. **Launch** from desktop shortcut or Start Menu

### Method 2: Portable Version
1. **Download** the portable version
2. **Extract** to any folder
3. **Run** `SURA-RESTO-by-SURA.exe` directly
4. **No installation required**

## 🖥️ System Requirements

### Minimum Requirements
- **OS**: Windows 10 (64-bit) or Windows 11
- **RAM**: 4GB
- **Storage**: 500MB free space
- **Internet**: Required for Firebase sync
- **Printer**: USB or Network printer (optional)

### Recommended Requirements
- **OS**: Windows 11 (64-bit)
- **RAM**: 8GB or more
- **Storage**: 1GB free space
- **Internet**: High-speed connection
- **Printer**: Thermal receipt printer

## 🔧 First-Time Setup

### 1. Launch Application
- Double-click the desktop shortcut or run the executable
- Wait for initial loading (may take 30-60 seconds)

### 2. Login Setup
- **Manager Login**: Use your existing Firebase credentials
- **Owner Login**: Use your existing Firebase credentials
- **Offline Mode**: Available if internet is unavailable

### 3. Printer Configuration
- **Connect your printer** to the computer
- **Check toolbar** for printer connectivity status
- **Test printing** with a sample bill

### 4. Restaurant Profile
- **Owner Dashboard** → Profile → Edit Restaurant Profile
- **Update** restaurant name, address, GSTIN, contact details
- **Save** changes

## 🖨️ Printer Setup

### USB Printer
1. **Connect** printer via USB cable
2. **Install** printer drivers (if required)
3. **Set as default** printer in Windows
4. **Check** connectivity status in app toolbar

### Network Printer
1. **Connect** printer to same network
2. **Add** network printer in Windows
3. **Set as default** printer
4. **Verify** connectivity in app

### Printer Status Indicators
- 🟢 **Green**: Printer connected and ready
- 🔴 **Red**: No printers detected
- ⚪ **Gray**: Desktop mode only (no printer access)

## 🛠️ Troubleshooting

### Common Issues

#### App Won't Start
- **Check** Windows Defender/Firewall settings
- **Run** as Administrator
- **Verify** .NET Framework is installed
- **Check** antivirus software exclusions

#### Printer Not Detected
- **Verify** printer is connected and powered on
- **Check** Windows printer settings
- **Restart** the application
- **Test** printer in Windows

#### Internet Connection Issues
- **Check** internet connection
- **Verify** Firebase credentials
- **Use** offline mode if needed
- **Contact** support if persistent

#### Performance Issues
- **Close** other applications
- **Restart** the application
- **Check** available RAM
- **Update** graphics drivers

### Error Messages

#### "No printers connected"
- **Connect** a printer to your computer
- **Use** "Save Only" option to save bill for later printing
- **Check** printer drivers and connections

#### "Electron API not available"
- **Restart** the application
- **Run** as Administrator
- **Check** antivirus exclusions

#### "Failed to save bill"
- **Check** internet connection
- **Verify** Firebase credentials
- **Try** offline mode
- **Contact** support if persistent
